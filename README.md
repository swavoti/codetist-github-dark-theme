# GitHub Dark Theme for Codetist

The classic, razor-sharp GitHub Dark theme adapted for Codetist IDE.

## Features

- **GitHub Dark Palette**: Exact background (`#0d1117`), sidebar (`#010409`), and border (`#30363d`) tones.
- **Accurate Syntax Highlighting**:
  - Keywords & Control: `#ff7b72`
  - Functions: `#d2a8ff`
  - Strings: `#a5d6ff`
  - Numbers & Constants: `#79c0ff`
  - Types & Classes: `#ffa657`
  - Comments: `#8b949e` (italic)
  - Tags & Regex: `#7ee787`
- **Full Terminal & UI Integration**: Perfectly synchronized status bar, tabs, active borders, and ANSI terminal colors.
